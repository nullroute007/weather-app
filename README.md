# UFUQ (أفق) — Hyper-Local Atmospheric Weather PWA

**UFUQ** (*meaning "Horizon" in Arabic*) is a modern, luxury Progressive Web App (PWA) designed to deliver hyper-local, real-time weather intelligence—from major global metropolises down to small towns and villages.

---

## ✨ Key Features

- **Hyper-Local Village & City Search:** Powered by Open-Meteo Geocoding and OpenStreetMap Nominatim to search everything from major cities to rural villages (e.g., *Harchoke, Chunian, Kasur, Punjab, Pakistan*).
- **Interactive Labeled Map Picker:** Explore any region on an interactive map and tap anywhere to fetch instant atmospheric conditions for that exact coordinate.
- **Dynamic Visuals & Live Particles:** Full-screen atmospheric wallpapers with subtle Ken Burns motion and real-time HTML5 Canvas weather particles (rain, drifting mist, golden sun-motes, and starry night skies).
- **Cinema-Grade 5-Second Intro:** Smooth storm-to-sunrise canvas preloader transition on startup.
- **Comprehensive Atmospheric Insights:**
  - 24-Hour Interactive Timeline & 7-Day Extended Forecast
  - Real-Time Air Quality Index (US AQI, PM2.5, PM10)
  - Daylight Sunrise & Sunset Horizon Arc, UV Index, Visibility, and Barometric Pressure
- **1-Click Installable Mobile & Desktop App (PWA):** Installable directly onto Android, iOS, and Desktop home screens for a native full-screen app experience.

---

## 🛠️ Built With

- **HTML5 & CSS3** (Glassmorphism UI, Responsive Grid & Flexbox)
- **Vanilla JavaScript (ES6+)** (HTML5 Canvas Physics, Service Worker, PWA Install Prompt)
- **Leaflet.js** (Interactive Labeled Map)
- **Open-Meteo API & OpenStreetMap** (Real-Time Weather, Air Quality & Geocoding)

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the folder and double-click `index.html` in any modern web browser.
3. For full **1-Click PWA App Installation**, host the files on **GitHub Pages**, **Netlify**, or **Vercel** over `HTTPS`.
